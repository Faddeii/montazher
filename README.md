# Монтажёр ✂

Бесплатная программа для черновой чистки видео. Загружаете запись, она сама находит **паузы, мычание («эээ», «ммм»), слова-паразиты, оговорки, дубли и мат**. Вы проверяете разметку в браузере и получаете:

- готовый **MP4**;
- **проект CapCut**, где видео уже нарезано на куски;
- проект для **Premiere Pro / DaVinci Resolve** (XML) и EDL.

Всё работает на вашем компьютере: видео никуда не загружается, подписок и оплаты нет.

## Установка (Windows 10/11)

1. Скачайте архив `Montazher.zip` со страницы [Releases](../../releases) и распакуйте в любую папку.
2. Дважды кликните **`start.bat`**.
   - Первый запуск сам установит Python, ffmpeg и нужные библиотеки. Это 5–15 минут и около 3 ГБ.
   - При первой обработке видео один раз скачивается модель распознавания речи (≈1,5 ГБ).
3. Откроется браузер со страницей программы. Не закрывайте чёрное окно, пока пользуетесь программой.

Дальше запуск тем же `start.bat`, он занимает пару секунд.

**Видеокарта.** С видеокартой NVIDIA пятиминутное видео обрабатывается примерно за 30 секунд. Без неё всё тоже работает, но на процессоре в несколько раз медленнее.

## Как пользоваться

1. Перетащите видео на главную страницу.
2. Когда обработка закончится, откроется редактор с расшифровкой:
   - **зачёркнутое** будет вырезано, цвет показывает причину;
   - **клик по слову** вырезает его или возвращает обратно;
   - **выделите фразу мышью** и нажмите `Del`, чтобы вырезать её целиком;
   - **Ctrl+клик** переходит к этому месту в видео;
   - клик по метке паузы (`1.4с`) включает или выключает её сокращение;
   - переключатели слева включают и выключают целые категории (паузы, мычание, мат…);
   - «Просмотр с вырезами» проигрывает видео так, как оно будет смонтировано.
3. Заберите результат:
   - **«Отправить в CapCut (нарезкой)»**: проект сразу появится в CapCut для ПК, каждый кусок будет отдельным клипом на таймлайне. Если CapCut был открыт, перезапустите его.
   - **«Смонтировать MP4»**: готовый ролик, плюс XML для Premiere/DaVinci и EDL.

Не удаляйте видео в Монтажёре, пока работаете с его проектом в CapCut или Premiere: проект ссылается на исходник в папке `data`.

## Точнее с Claude (необязательно)

Без дополнительных настроек дубли, оговорки и паразиты ищутся встроенными правилами. Если нужно точнее, можно подключить ИИ Claude (платно, примерно $0.5–1 за час видео):

1. Получите ключ на [console.anthropic.com](https://console.anthropic.com/settings/keys).
2. Откройте файл `.env` в папке программы Блокнотом и впишите: `ANTHROPIC_API_KEY=ваш-ключ`.
3. Перезапустите `start.bat`.

## Если что-то не работает

- **Не установился Python или ffmpeg.** Нужен winget. Обновите «Установщик приложений» (App Installer) в Microsoft Store.
- **CapCut не видит проект.** Закройте и снова откройте CapCut. Если вы меняли папку проектов в настройках CapCut, укажите её в `.env` строкой `CAPCUT_DRAFTS=...`. Проект создаётся в формате CapCut 7.x, старые версии CapCut могут его не открыть.
- **Порт занят.** Поменяйте `PORT=8765` в `.env` на другое число.

## Как это устроено

| Шаг | Что делает | Где |
|---|---|---|
| Распознавание | faster-whisper (`large-v3-turbo`) с таймкодом каждого слова | `app/transcribe.py` |
| Мычание | по тексту и по звуку: голосовые участки вне слов и протяжки внутри слов перепроверяются Whisper | `app/acoustic.py` |
| Паразиты, оговорки, дубли | локальные правила или Claude | `app/local_rules.py`, `app/analyze.py` |
| Монтаж | всё между оставленными словами вырезается с запасом «воздуха» | `web/app.js` → `computeCuts` |
| Рендер | один проход ffmpeg, NVENC на видеокартах NVIDIA | `app/media.py` |
| Экспорт | CapCut, FCP7 XML, EDL | `app/capcut.py`, `app/export.py` |
